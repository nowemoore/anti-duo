# Handwriting reference data — sources and licences

This folder carries two independent sets of stroke reference patterns. They are kept in separate
files because they come from different projects under different licences.

## `draw-patterns.json` — KanjiCanvas (MIT)

Ships with [KanjiCanvas](https://github.com/asdfjkl/kanjicanvas) by Dominik Klein, MIT licensed,
along with the recogniser itself (`kanjicanvas.ts`). 298 patterns, kanji only.

## `kanjivg-patterns.json` — KanjiVG (CC BY-SA 3.0)

Derived from [KanjiVG](http://kanjivg.tagaini.net), copyright © 2009-2011 Ulrich Apel, released
under the [Creative Commons Attribution-Share Alike 3.0](https://creativecommons.org/licenses/by-sa/3.0/)
licence.

219 patterns: every kana codepoint the course uses (148, including the small ゃゅょ that yōon are
built from) plus the 71 curriculum kanji KanjiCanvas had no pattern for. Generated by
`scripts/gen-kanjivg-patterns.ts`, which samples KanjiVG's stroke paths and runs them through the
recogniser's own `momentNormalize` + `extractFeatures`.

**This file is a derivative work of KanjiVG.** Under Share Alike it must stay under CC BY-SA 3.0 (or
a compatible licence) and keep this attribution if the app is distributed. It is data rather than
code, and separable from the rest of the project, so it does not put the application's own licence
in question — but it must not be silently relicensed or stripped of attribution.

Regenerate with `npm run gen:patterns`; verify with `npm run check:handwriting`.
